# 发票自动化管理工具 (Invoice Automation Tool)

这是一个基于 Python 和 Streamlit 开发的轻量化工具，旨在帮助财务或个人一键处理发票。

## 主要功能
1. **多文件上传**：支持批量上传 PDF 电子发票。
2. **自动识别**：自动解析发票号码、公司名称、合计金额、开票日期（目前针对标准 PDF 发票优化）。
3. **自动归集**：上传后的文件会根据识别出的“公司名称”自动存入对应文件夹。
4. **Excel 导出**：生成结构化的汇总表，支持在线预览、微调及下载。

## 如何运行

### 1. 安装 Python
确保您的电脑已安装 Python 3.8 或更高版本。

### 2. 安装依赖库
在终端（或 CMD）中进入项目文件夹，运行：
```bash
pip install -r requirements.txt
```

### 3. 启动程序
运行以下命令启动网页界面：
```bash
streamlit run app.py
```

### 4. 使用
程序启动后会自动在浏览器打开一个页面。您只需将 PDF 发票拖入，即可看到识别结果并下载 Excel。

## Mac 用户一键运行指南

为了让你在 Mac 上能双击运行，我已经为你准备了 `运行发票工具.command` 文件。

### 第一次运行：
1.  **赋予执行权限**：打开“终端 (Terminal)”，输入 `chmod +x ` (后面带一个空格)，然后把 `运行发票工具.command` 文件拖进终端窗口，按回车。
2.  **双击运行**：之后你只需要双击该文件，它会自动安装环境并启动工具。

## 如何在“任何电脑”上打开？ (云端部署)

如果你希望在任何地方（不局限于自己的 Mac）都能使用：

1.  **GitHub 托管**：将代码上传到你的 GitHub 仓库。
2.  **部署到 Streamlit Cloud**：
    - 访问 [share.streamlit.io](https://share.streamlit.io/)。
    - 关联你的 GitHub 仓库。
    - 它会生成一个**永久链接**，你发给任何人或在任何电脑上打开该链接即可使用。

## 进阶建议
- **图片识别**：如果需要处理发票照片（JPG/PNG），建议在代码中接入 `PaddleOCR` 或阿里云/百度云的 OCR API 以获得更高的准确率。
- **高精度提取**：对于排版极度复杂的发票，建议接入 GPT-4o 或 DeepSeek 等大模型的 Vision 能力进行语义提取。
